# devlog — หลบรถตุ๊กตุ๊ก (game-01)

## 2026-10-13 — v0.1 ต้นแบบเล่นได้
- ทำ: `index.html` ไฟล์เดียว (HTML + Canvas + JS) เล่นบนมือถือ/คอมได้ ไม่ต้องติดตั้งอะไร
  - 3 เลน · แตะครึ่งซ้าย/ขวา หรือลูกศร ← → เปลี่ยนเลน
  - ตุ๊กตุ๊กสุ่มสีวิ่งสวน · เร็วขึ้นเรื่อย ๆ · คะแนนเป็น "เมตร" · เก็บสถิติในเครื่อง
  - หลัง 30 ม. มีตุ๊กตุ๊กมาทีละ 2 คัน แต่เว้นเลนว่างเสมอ (หลบได้จริง)
- ทดสอบ: จำลองเล่นในเบราว์เซอร์ ชน → จบเกม → แสดงสถิติ ถูกต้อง
- ติด: ยังไม่ได้ลองบนมือถือจริง · ภาพยังเป็นรูปทรงเรขาคณิต · ไม่มีเสียง
- ต่อไป: เสียง (แตร/ชน) · ไอเทม · ฉากถนนไทย (ป้าย ร้านข้างทาง) · เผยแพร่ให้คนดูเล่น

## 2026-10-13 — v0.2 เสียง + ฉากถนนไทย
- เสียงทั้งหมดสร้างด้วย Web Audio (ไม่มีไฟล์เสียง ไม่ติดลิขสิทธิ์): เปลี่ยนเลน "ติ๊ก", ตุ๊กตุ๊กเข้าเลนเรา "ปี๊น ปี๊น", ชน "โครม", เริ่มเกม
- ฉากข้างทาง: ห้องแถวกันสาดลายทาง + ป้ายร้านภาษาไทย (ข้าวมันไก่ ก๋วยเตี๋ยว ส้มตำ ฯลฯ) ต้นไม้ เสาไฟสายไฟ ขอบฟุตบาทขาวแดง เลื่อนตามความเร็ว
- AI ทำพัง: เรียก reset() ก่อนประกาศ const รายชื่อร้าน → ReferenceError (TDZ) · แก้โดยย้าย reset() ไปก่อนเริ่ม loop
- ยังไม่ได้ฟังเสียงจริง (ผู้ใช้ไม่มีลำโพง) · ยังไม่ทดสอบบนมือถือ
